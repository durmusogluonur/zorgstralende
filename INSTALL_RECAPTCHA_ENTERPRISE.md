# reCAPTCHA Enterprise Paket Kurulumu

## Hızlı Kurulum

```bash
npm install @google-cloud/recaptcha-enterprise
```

## Kurulum Sonrası

1. Paket yüklendikten sonra build çalışacak
2. Google Cloud credentials yapılandırması için `RECAPTCHA_ENTERPRISE_SETUP.md` dosyasına bakın

## Not

Eğer Google Cloud SDK kullanmak istemiyorsanız, kod otomatik olarak basic reCAPTCHA verification'a fallback yapacaktır.
